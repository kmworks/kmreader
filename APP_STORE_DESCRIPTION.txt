KMReader - Native Komga Client for iPhone, iPad, Mac, and Apple TV

Read, browse, download, and manage your Komga library with native Apple-platform readers, responsive local storage, and reliable offline workflows.

IMPORTANT FEATURES

- Native readers
Read DIVINA comics on iOS, macOS, and tvOS, plus EPUB and PDF on iOS and macOS. Enjoy LTR, RTL, vertical and Webtoon modes, spreads, zoom, page curl or cover transitions, custom EPUB typography, PDF search, keyboard shortcuts, per-book preferences, animated pages, AI upscaling, and progress-free Peek reading.
On iPhone and iPad, Panel Mode walks through paged comics panel by panel with an explicitly downloadable detection model. Optional volume-button page turns work across DIVINA, EPUB, and PDF. Rotate pages, crop empty borders, tune preloading, and keep lightweight progress visible.
Translate manga with downloadable on-device OCR model packs and your choice of system translation or a custom AI provider. Per-page controls render translations over the original bubbles, including vertical typesetting.

- Browse and discover
Keep Reading, On Deck, Recently Added, Recently Updated, Read Lists in Progress, reading history, a pages-read heatmap, saved filters, and rich metadata filters help you find what to read next. Continue ordered read lists like series, create live smart lists on supported servers, and view reading streaks and stats.
Filter by characters, teams, locations, and other notable entities. Select multiple items to update reading status or add them to lists. Use widgets, Spotlight, Home Screen quick actions, and dedicated iPhone Library, Lists, and Search tabs.

- Offline and sync
Download DIVINA, EPUB, and PDF books, set per-series and per-read-list policies, and browse downloads with count and storage summaries. Offline-first reading prepares local content before opening; large downloads stream to disk and missing covers sync for offline browsing.
Progress and offline changes sync when you reconnect. iOS background downloads and Live Activities keep long transfers visible.

- Multi-server, trackers, and admin tools
Save multiple Komga servers, protect private servers with device authentication, and switch instantly. Sign in with password or API key, create a key or a new Komga server from the login screen, and manage API keys in the app.
On supported servers, manage AniList, MyAnimeList, Bangumi, and MangaBaka tracker accounts and series links, review sessions and server updates, and use smart lists, server-side stats, and komf metadata fetching.
Edit metadata, manage libraries and media, find missing posters or duplicates, and browse, export, or clear logs. Server Info reports version, uptime, resources, content totals, tasks, and sessions.

KMReader targets Komga 1.20.0+ and supports API v1/v2.
Localized in English, German, French, Japanese, Korean, Simplified Chinese, Traditional Chinese, Italian, Russian, and Spanish.
