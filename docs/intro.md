# Getting started

KMReader is a native Komga client for iOS, macOS, and tvOS.

## 1. Download

Get KMReader on the [App Store](https://apps.apple.com/app/id6755198424). It requires iOS 17.0, macOS 14.0, or tvOS 17.0.

## 2. Add your Komga server

Open Settings and add a server with its address, for example `https://komga.example.com`. You can save multiple servers and switch between them at any time.

## 3. Sign in

Sign in with your Komga username and password, or with an API key. Keys can be created and managed in the app.

:::note
Any Komga 1.20.0+ server works, including [kmrs](https://kmworks.github.io/kmrs/), the single-binary Rust server from the same family.
:::
