New
- EPUB on iOS gains an optional Core Text engine with paged, scrolled, cover, and page-curl layouts, embedded fonts, themes, offline resources, and reliable reading-position restoration.
- Manga translation on iOS and macOS now has a Live Text-style button on every displayed page. Translate one page or switch between original and translated text independently, including individual pages in a spread.
- On supported servers, smart lists can be pinned alongside collections and read lists, with pinned items appearing first on the Lists page and in browse results.
- New translation providers start with OpenRouter preselected, while custom endpoints remain available.

Reader
- Translated bubbles are easier to read: English words stay intact when wrapping, text adapts to light and dark backgrounds, and backgrounds no longer blur the original bubble border.
- Translation now skips pages whose source and target languages match, treating Simplified and Traditional Chinese as the same language. Page-level translation is no longer offered in Webtoon mode.
- Core Text EPUB rendering improves oversized images, table layouts, line spacing, margins, superscripts, subscripts, and letter spacing. A chapter that cannot render becomes an inline error page instead of blocking the whole book.
- Choose what the Space bar does while reading: Toggle Controls or Next Page, across DIVINA, EPUB, and PDF with an external keyboard.
- The iOS Home indicator hides automatically while reading.

Browse & Offline
- Pinned libraries now lead library scope selectors, and the iPad Libraries tab opens the pinned scope by default.
- Collection, read list, and smart list menus now share a consistent set of actions.
- Connection status uses compact icons instead of the persistent Dashboard offline banner, and successful downloads no longer interrupt reading with a completion toast.
- Scenario-based user guides are available from Settings → About.
